# تطبيق حجز المواعيد | Appointment Booking App

تطبيق ويب ثنائي اللغة (عربي / إنجليزي) لحجز المواعيد في العيادات والصالونات.

## الميزات
- اختيار الخدمة (قص شعر، صبغة، استشارة، عناية بشرة، مانيكير)
- اختيار التاريخ والوقت مع منع التعارض
- نموذج بيانات العميل
- صفحة تأكيد
- عرض وإدارة الحجوزات
- حفظ محلي في المتصفح

## الاستخدام
افتح ملف `index.html` في المتصفح أو انشره على أي استضافة ثابتة.
